# LLMegeton

*Field guide to existing LLM models and tips for directing your digital daemons.*

A grimoire, in the old sense, is a book of instructions for directing spirits — what to say, what to draw, what order to do things in so the summoned thing does what you want. This is that, for language models.

## What's inside

- **[Capabilities](capabilities/index.md)** — what LLMs can actually do, where they're strong, where they fall over. The honest map, not the marketing.
- **[Prompts](prompts/index.md)** — reusable prompt patterns: the evocations. Role framing, few-shot, chain-of-thought, structured output, and friends — each with when to reach for it.
- **[Skills](skills/index.md)** — agent skills as shareable units: what they are, how they're structured, and how to adapt one to your own agent.

## How to use this

Steal freely. Everything here is meant to be copied, remixed, and plugged into your own agents and workflows. If a prompt works, take it. If a capability note saves you an afternoon of arguing with a model, good.

## Contributing

Found a capability worth documenting, or a prompt pattern that deserves a page? Open a PR — the grimoire grows by accumulation.
